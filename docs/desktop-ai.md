# 桌面 AI 使用方式

在自己的电脑上主动打开 Codex 或其他 AI 助手，发起资料整理请求。玩迹网页只提供说明与复制文本，不创建远程任务，不配对电脑，也不会触发本机进程。

## 当前可用

1. 在游戏详情打开「桌面 AI 补全」，或者在添加游戏页面打开「在电脑上用 AI 整理」。
2. 复制任务说明，在电脑上的 AI 助手中主动发送。旧链接中的 `prompt` 参数不会被使用或自动发送。
3. 核实游戏版本、发行年份、MC 评分和图片；游玩时长、状态和评价由自己填写。
4. 在玩迹的新增 / 编辑表单中录入资料并上传图片，检查后保存。

主题页面同样提供桌面整理说明；已有主题继续按保存的配置聚合游戏。

## 后续 API 接入的边界

无需发布专门的 CLI。可以为桌面 AI 提供 API 文档和独立、可撤销的访问令牌，让用户主动发起 HTTPS 请求。

这项桌面令牌接入尚未实现。当前游戏接口仍使用浏览器邀请码会话，不能将旧设备令牌当作游戏管理令牌使用，也不应把 Supabase 管理密钥放进 AI 提示词。

未来接口必须由后端校验权限、允许修改的字段、记录版本及用户归属；桌面工具的预览与确认不替代后端验证。不得恢复网页任务队列、电脑轮询执行或远程启动功能。

## 停用边界

后端在读取任何凭证和访问数据库之前就拒绝旧 AI 路由，旧网页和旧设备密钥也无法调用任务通道。恢复旧程序入口无效，只要后端仍部署当前版本。

数据库历史记录及权限未改变。若回滚到仍包含远程 AI 接口的旧后端版本，可能重新开放通道，因此回滚版本也必须保留停用路由。旧设备记录不是当前有效的远程执行入口。
