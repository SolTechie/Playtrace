# 本机 AI 连接

## 使用

1. 在电脑上安装并登录 Codex。连接服务会优先查找 Codex / ChatGPT 桌面应用附带的 CLI，也可在 `.env.bridge` 中指定 `CODEX_BIN`。
2. 在玩迹输入管理邀请码，打开「AI 工作台 → 连接电脑」，建立设备。复制只显示一次的设备令牌。
3. 将 `.env.bridge.example` 复制为 `.env.bridge`，填入网站 HTTPS 地址和设备令牌。
4. 在项目目录执行：

```sh
npm run bridge
```

也可以用本机已保存的邀请码自动配对（首次运行，不覆盖已有设备配置）：

```sh
npm run bridge:setup -- https://playtrace.liyuqiaolucky.workers.dev
npm run bridge
```

该脚本仅向指定的自己的网站发送邀请码，临时管理会话在配对后退出；设备令牌保存在 `.env.bridge`，不提交 Git。停用邀请码会立即禁用其网页会话，但已配对的电脑需在工作台中单独撤销设备。

保持此进程运行。网页输入「添加空洞骑士，Steam，2026 年玩了 40 小时，已完成」后，工作台会显示电脑是否在线、实际搜索进度和整理结果。AI 只填入有依据的客观资料，主观记录由指令或用户填写；保存前可修改全部字段。

不需要在网页输入 OpenAI API key；AI 使用本机 Codex 登录状态与相应额度。手机也可以发起请求，只要配对电脑上的连接服务正在运行。

## 处理流程

任务持久化在 Supabase；连接服务以设备令牌领取任务，使用独立租约防止两台电脑重复处理。20 秒心跳延长租约，掉线后可以恢复；过期重领最多三次，之后网页可手动重试。

Codex 在临时目录中以只读、无 shell 工具模式运行，使用真实搜索。网页收到简短工具进度，不接收内部推理文本。本机连接令牌、Supabase key 和其他应用环境变量不会传给 Codex 子进程。临时草稿文件在完成后清理。

主题 AI 仅生成固定配置：筛选字段、图表种类、排序、画廊或时间线。不会执行模型返回的代码、SQL 或任意页面脚本。

## 检查与故障

- 一直「等待电脑」：启动连接服务，检查网站地址和设备令牌。
- 401 / 403：设备已撤销或所属档案管理员已移除，重新配对。
- 搜索失败或超时：检查 Codex 登录、联网与额度，再在工作台重试。
- 未能确定同名游戏：在工作台补充平台、年份或英文名称。
- 按 Ctrl+C 可停止本机服务；未完成任务会通过租约恢复。

`npm exec tsx scripts/smoke-codex.ts` 可测试真实 Codex 搜索能力，只生成本地草稿，不向游戏库保存。
